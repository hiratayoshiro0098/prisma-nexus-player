## 🚀 Quick Start

### ⚡ Fastest Way (No Tech Skills Needed)

1. **Download** `PrismaNexusPlayer.exe` from [Releases](https://github.com/YOUR_USERNAME/prisma-nexus-player/releases)
2. **Double-click** the file
3. **Browser opens automatically** - that's it!

```bash
# Step 1: Install Python from python.org if you don't have it

# Step 2: Open Terminal/Command Prompt

# Step 3: Install requirements
pip install flask flask-cors

# Step 4: Navigate to the app folder
cd prisma-nexus-player

# Step 5: Run the app
python app.py
