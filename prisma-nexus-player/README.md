## 🎯 Overview

PrismaNexus Player (PNP) is a stunning, feature-rich media player that plays videos, audio, and images directly in a beautiful glass-morphism interface. Built with Python and modern web technologies, it offers a premium media experience with volume boosting up to 300%.

## ✨ Features

### 🎬 **Media Playback**
- **Built-in Video Player**: Watch videos directly in the app (no external player needed)
- **Audio Player**: Play music with beautiful visualization
- **Image Viewer**: View photos with smooth display
- **300% Volume Boost**: Go beyond normal volume limits
- **Supports All Major Formats**: MP4, AVI, MKV, MOV, MP3, WAV, FLAC, JPG, PNG, GIF, and more

### 🎨 **Beautiful UI**
- **Glass Morphism Design**: Modern, translucent interface
- **Dark Theme**: Easy on the eyes
- **Smooth Animations**: Fluid transitions and effects
- **Equalizer Visualization**: Animated audio bars
- **Responsive Layout**: Adapts to different screen sizes

### 🎮 **Controls**
- **Keyboard Shortcuts**: Space (play/pause), Arrows (navigate/volume), M (mute)
- **Progress Bar**: Click to seek anywhere in the media
- **Volume Slider**: Precise control up to 300%
- **Playlist Management**: Easy file browsing and playback

### 📂 **File Management**
- **Quick Folder Scanning**: Scan Music, Videos, Downloads folders
- **Smart File Detection**: Automatically identifies media types
- **Large Library Support**: Handles hundreds of files efficiently
- **One-Click Play**: Double-click any file to play
