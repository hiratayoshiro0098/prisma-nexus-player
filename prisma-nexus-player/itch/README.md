# PrismaNexus Player - itch.io Page Content

## Short Description
A beautiful, modern media player with built-in video, audio, and image support. Features 300% volume boost and stunning glass-morphism UI.

## Full Description
PrismaNexus Player (PNP) is a feature-rich media player that combines beautiful design with powerful functionality. Watch videos, listen to music, and view images all in one stunning application.

### Key Features:
- 🎬 Built-in video player (no external apps needed)
- 🎵 Audio player with equalizer visualization
- 🔊 Volume boost up to 300%
- 🎨 Glass morphism UI design
- ⌨️ Full keyboard shortcuts
- 📁 Smart folder scanning
- 🌐 Cross-platform support

### Perfect For:
- Watching movies and videos
- Listening to music collections
- Viewing photo galleries
- Anyone who wants a beautiful media player
