# PrismaNexus Player - User Guide

## Getting Started

### First Launch
1. Run `PrismaNexusPlayer.exe` or `python app.py`
2. Your default browser will open automatically
3. The app runs at `http://127.0.0.1:5000`

### Loading Media
1. Click **Scan Music** to load audio files
2. Click **Scan Videos** to load video files
3. Use **Quick Access** folders for faster navigation

### Playing Media
- **Single click**: Select and play a file
- **Double click**: Instant playback
- **Space bar**: Play/Pause
- **Arrow keys**: Navigate between files

## Features

### Video Player
- Plays MP4, AVI, MKV, MOV, WebM
- Full video controls
- Click progress bar to seek
- Smooth playback

### Audio Player
- Plays MP3, WAV, FLAC, AAC, OGG
- Visual equalizer
- Album art display
- Background playback

### Image Viewer
- Views JPG, PNG, GIF, WebP
- Full-size display
- Instant loading

### Volume Control
- Normal range: 0-100%
- Boost range: 101-300%
- Mute toggle (M key)

## Tips & Tricks

1. **Scan multiple folders** to build a large playlist
2. **Use keyboard shortcuts** for faster control
3. **Volume boost** is great for quiet videos
4. **Keep browser open** - the app runs as a server

## Troubleshooting

### Video won't play
- Ensure the format is supported (MP4 recommended)
- Try converting the file to MP4
- Check if the file isn't corrupted

### App won't start
- Check if Python is installed
- Ensure port 5000 isn't in use
- Run as administrator if needed

### Browser doesn't open
- Manually navigate to http://127.0.0.1:5000
- Check firewall settings
